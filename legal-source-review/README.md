## 一、来源口径

- 只采用全国人大/国家法律法规数据库、中国政府网、国务院部门官网、最高人民法院官网及最高人民法院公报。
- 本目录中的 HTML/PDF 是官方发布页面的离线快照；`scripts/build-legal-basis-data.js` 会抽取正文、拆分条文并生成带版本元数据的 `js/legal-basis-data.js`。
- 司法解释不是越多越好。建议由“通用核心规则 + 合同类型触发规则”组成，避免无关法规占用模型上下文并造成错误援引。
- 法律版本必须同时记录公布日、施行日、失效日（如有）和来源地址，不能只凭标题判断现行效力。

## 四、版本与接入风险提示

1. **商标法存在“已公布但尚未生效”的双版本窗口。** 2026修订版只能作为未来版本归档；在2026-12-31以前，审核引用仍应指向2019修正版。
2. **公司法不能只替换法条文本。** 2023修订公司法已经施行，但涉及旧行为、持续履行或旧公司决议时，需要同时适用法释〔2024〕7号的时间效力规则。
3. **劳动争议司法解释（二）改变了部分旧规则。** 其第二十一条明确，自2025-09-01起施行，并同时废止司法解释（一）第三十二条第一款；入库时必须做条级覆盖关系，不能让两个冲突条文同时命中。
4. **知识产权司法解释不能再统一停留在2020版本。** 著作权民事纠纷解释已于2026-09-01实施第二次修正；知识产权惩罚性赔偿解释也于2026-05-01换版并明确废止2021版。
5. **司法解释按合同类型检索，不整份发送给模型。** 建议先由合同分类器确定候选法规，再按条文标签召回最相关依据。
6. **建设工程解释必须同时包含（一）和（二）。** 解释（二）自2026-06-30施行，并规定此前司法解释与其不一致的，以解释（二）为准。
